 # Portfolio Web & Infrastructure
 ## Présentation

Réalisation d’un portfolio web dans le cadre du projet transversal.
Objectif : créer un site personnel et comprendre son hébergement.

## Parcours

Parcours A – Infrastructure
Dans ce parcours, l’accent est mis sur :

la mise en place d’un environnement d’hébergement
la compréhension du fonctionnement d’un serveur web
l’accès au site via une machine virtuelle

## Technologies

HTML, CSS, Apache, Machine virtuelle Linux
